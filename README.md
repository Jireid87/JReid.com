# James Reid CV

This repository contains a simple static resume for James Reid. The site is built with plain HTML and CSS and can be hosted anywhere that serves static files.

## Local preview

Serve the files locally with Python:

```bash
python -m http.server 8000
```

then open [http://localhost:8000](http://localhost:8000) in your browser.

## Deployment

Upload the contents of this repository to any static hosting provider such as GitHub Pages, Netlify, or Vercel.
